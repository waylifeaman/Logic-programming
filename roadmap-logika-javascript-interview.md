# Checklist Roadmap: Logika Programming JavaScript untuk Coding Interview

> Cara pakai: centang `\[x]` setiap topik/latihan yang sudah selesai. Kerjakan berurutan dari Fase 1.

\---

## Fase 1: Fondasi JavaScript

### Konsep

* \[ ] Variabel \& tipe data (`string`, `number`, `boolean`, `null`, `undefined`)
* \[ ] Operator aritmatika, perbandingan, logika (`\&\&`, `||`, `!`)
* \[ ] `if/else`, `switch`, ternary operator
* \[ ] Looping: `for`, `while`, `do-while`
* \[ ] Function: declaration, expression, arrow function
* \[ ] Parameter, default value, return value
* \[ ] Scope: `let`, `const`, `var`, hoisting dasar

### Latihan

* \[ ] FizzBuzz
* \[ ] Cek angka prima
* \[ ] Hitung faktorial
* \[ ] Cek palindrome (angka/string)
* \[ ] Konversi suhu / kalkulator sederhana

\---

## Fase 2: Struktur Data Bawaan JS

### Konsep

* \[ ] Array: `push`, `pop`, `slice`, `splice`
* \[ ] Array higher-order: `map`, `filter`, `reduce`, `find`, `sort`, `includes`
* \[ ] Object: akses properti, `Object.keys/values/entries`
* \[ ] Destructuring (array \& object)
* \[ ] String manipulation: `split`, `slice`, `indexOf`, `replace`, `charAt`, `toUpperCase/toLowerCase`
* \[ ] `Set` dan `Map`

### Latihan

* \[ ] Reverse string tanpa built-in `.reverse()`
* \[ ] Hitung frekuensi karakter dalam string
* \[ ] Cari elemen duplikat di array
* \[ ] Cek dua string anagram
* \[ ] Flatten nested array sederhana

\---

## Fase 3: Logika Pemrograman Inti

### Konsep

* \[ ] Nested loop \& kondisi kompleks
* \[ ] Early return, `break`, `continue`
* \[ ] Rekursi: base case \& recursive case
* \[ ] Pattern: Two Pointers
* \[ ] Pattern: Sliding Window
* \[ ] Pattern: Frequency Counter
* \[ ] Pattern: Hash Map untuk lookup cepat (O(1))

### Latihan

* \[ ] Fibonacci (iteratif \& rekursif)
* \[ ] Two Sum problem
* \[ ] Longest substring tanpa karakter berulang
* \[ ] Cek palindrome dengan two pointers
* \[ ] Group anagram

\---

## Fase 4: Struktur Data \& Algoritma Dasar

### Konsep

* \[ ] Stack (konsep + implementasi manual)
* \[ ] Queue (konsep + implementasi manual)
* \[ ] Linked List (singly, konsep dasar)
* \[ ] Binary Tree (konsep, traversal)
* \[ ] Sorting: bubble sort, selection sort (paham cara kerja)
* \[ ] Searching: linear search, binary search
* \[ ] Big O Notation: time \& space complexity dasar

### Latihan

* \[ ] Implementasi Stack manual (push/pop)
* \[ ] Implementasi Queue manual (enqueue/dequeue)
* \[ ] Valid parentheses (pakai stack)
* \[ ] Binary search manual
* \[ ] BFS / DFS sederhana pada tree

\---

## Fase 5: Latihan Intensif Gaya Interview

* \[ ] Selesaikan 20+ soal Easy di LeetCode (tag: Array, String, Hash Table)
* \[ ] Selesaikan HackerRank "Interview Preparation Kit" (minimal section Arrays \& Strings)
* \[ ] Mulai naik ke soal Medium (minimal 10 soal)
* \[ ] Latihan "think out loud" — jelaskan pendekatan sebelum ngoding
* \[ ] Latihan dengan timer 30–45 menit per soal
* \[ ] Review ulang semua soal yang gagal/stuck, catat pattern-nya
* \[ ] Simulasi mock interview (dengan teman atau rekam sendiri)

\---

## Tips Cepat Sebelum Interview

* \[ ] Biasakan breakdown soal jadi langkah kecil di comment sebelum ngoding
* \[ ] Gunakan naming variabel yang jelas dan readable
* \[ ] Selalu cek edge case (array kosong, input negatif, dll)
* \[ ] Latihan menyebutkan kompleksitas Big O dari solusi sendiri
* \[ ] Jangan menghafal solusi — pahami pattern-nya
